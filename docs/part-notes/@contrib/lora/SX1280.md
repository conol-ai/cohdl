## Summary

The SX1280 is a 2.4 GHz half-duplex transceiver for LoRa, FLRC and (G)FSK (BLE PHY compatible), with a time-of-flight ranging engine (ds p. 1). It covers 2400–2500 MHz, transmits up to 12.5 dBm at 24 mA, and reaches −132 dBm LoRa sensitivity at SF12/203 kHz in high-sensitivity mode (ds p. 20, p. 22, p. 26). Its host interface is SPI (up to 18 MHz) or UART on the same four pins; the first valid transaction after power-up selects one (ds p. 59, p. 60). It runs from 1.8–3.7 V with a separate VBAT_IO for the host I/O, uses a 52 MHz crystal, and has an internal DC-DC whose output DCC_FB must feed VDD_IN (ds p. 17, p. 26). Semtech gives a complete reference design with matching network and BOM (ds pp. 145–146).

## Typical application

- Reference design (Figure 15-1, ds p. 145; BOM Table 15-1, ds p. 146):
  - RF path from RFIO: match C0 0.8 pF shunt, L1 3.0 nH series; then a pi filter C1 1.2 pF, L2 2.5 nH with C4 0.5 pF across it, C2 1.2 pF; then C3 100 pF DC block to the antenna. C3 lets a DC-grounded antenna be used without disturbing the internal DC bias on RFIO (ds p. 145).
  - DC-DC: L4 15 µH (Murata MLZ2012M150W) from DCC_SW (pin 14) to the V_DCC node on DCC_FB (pin 12), with C9 470 nF; VDD_IN (pin 2) is on the V_DCC node with C6 10 nF (ds p. 145, p. 146).
  - Decoupling: C5 10 nF on VR_PA, C8 100 nF on VBAT_IO, C10 100 nF on VBAT (ds p. 145).
  - Crystal: Q1 NDK NX2016SA 52.000 MHz, ±10 ppm, CL = 10 pF; no external load capacitors, the foot capacitors are internal (ds p. 145, p. 146).
- LDO-only operation drops the 15 µH inductor between pins 12 and 14 at higher energy use (ds p. 32); Figure 15-4 shows that variant (ds p. 147). Select the regulator with SetRegulatorType in STDBY_RC only (ds p. 32).
- TCXO (optional): 0.8 V clipped-sine type, AC-coupled into XTA (Figure 15-3, ds p. 147).
- Interface selection: both SPI and UART are enabled at power-up until the first valid transaction (ds p. 59). Pin 18 is driven low through a high-impedance driver until then, and becomes an input with pull-down if SPI is detected (ds p. 59). On a shared SPI bus, reset each SX1280 before its first SPI transaction (ds p. 65).
- SPI is mode 0 (CPOL = 0, CPHA = 0); wait for BUSY low before each command (ds p. 59, p. 60).
- For lowest sleep current, hold NSS high, SCK low, NRESET high and leave MISO high-impedance (Table 15-2, ds p. 148).

## Layout notes

- Land pattern (Figure 17-3, ds p. 153): C = 4.00 mm, G = 3.20 mm, Z = 4.80 mm, Y = 0.80 mm, X = 0.30 mm, P = 0.50 mm, H = K = 2.70 mm. `QFN24N50P400X400_1EP270X270` (0.8 × 0.3 mm lands on ±2.0 mm centres, 2.7 mm centre land) matches.
- Package (Figure 17-1, ds p. 152): 4.00 mm body, 0.50 mm pitch, L 0.35–0.45 mm, b 0.18–0.30 mm, exposed pad 2.55–2.65 mm with a chamfer at pin 1.
- Thermal vias in the exposed land must go to a system ground plane (Figure 17-3 note 3, ds p. 153). The θJA of 50.3 °C/W was computed with 9 thermal vias on a 4-layer JEDEC board (ds p. 154). The library footprint has no vias.
- Semtech's reference PCB layout is Figure 15-2 (ds p. 146).

## Pitfalls

- VDD_IN connects to DCC_FB (pin 12), not to VBAT (ds p. 17, p. 145). This is the opposite of the SX1262, whose VDD_IN goes to VBAT.
- The SX1280 PA tops out at 12.5 dBm (ds p. 26); it is not a +22 dBm part.
- The interface is latched by the first valid transaction (ds p. 59). Noise or another device's traffic on a shared bus before the first command can select the wrong interface; reset the radio first (ds p. 65).
- In UART mode pin 18 is an RTS output and pin 19 a CTS input (ds p. 64); the default UART frame uses even parity and CTS flow control (ds p. 64).
- RF input above 0 dBm is outside the operating range (ds p. 19).

## Not established by the sources

The library pad numbers, names and footprint geometry agree with the data sheet (Table 2-1 and Figure 2-1, ds pp. 17–18; Figure 17-3, ds p. 153). Gaps and disagreements:

- **Source URL:** the README gives only `https://www.semtech.com`; neither it nor the PDF gives a document URL.
- **Pin 19 name:** the library calls it `NSS_CTSN`; Table 2-1 calls it `NSS_CTS` (ds p. 17), while §9.5 calls the UART function `CTSN` (ds p. 64). The function is the same.
- **Reference-design numbering:** Figure 15-1 numbers the exposed pad 25 (ds p. 145); Table 2-1 numbers it 0 (ds p. 17), as the library does. The text under Figure 15-1 calls it "Figure 14-1", and §3 refers to "Section 15.1 … on page 145" (ds p. 19, p. 145).
- **ESD:** only the JEDEC classes are given, not voltages (ds p. 19).
- **Tmr:** Table 3-1 labels −55 to 115 °C only "Temperature" (ds p. 19).
- **NRESET timing:** the data sheet gives no minimum reset pulse width for the SX1280.
- **Courtyard:** the library's 5.3 mm courtyard is not from the source.

# SGM2554 — SGMICRO 1.1A load switch, SOT-23-5

Pinout (SOT-23-5): 1=IN, 2=GND, 3=EN, 4=NC, 5=OUT.

- Supply input 2.2-5.5V per datasheet (SGM2554, April 2022, REV. A.4;
  earlier note in this file said 1.0-5.5V — verify EN/input thresholds
  against the datasheet before tape-out), continuous load current up to
  1.1A (datasheet-rated current depends on package/PCB).
- Active-high enable (EN high = switch on).
- Used in the three-controller watch design as U9 to gate the ESP32-S3
  VDD3P3 rail; EN driven by SF32 GPIO PA11.

Datasheet: SGMICRO SGM2554 (www.sg-micro.com), committed locally as
`sgm2554.pdf` (SHA-256
58d6e47c130c08cdf6f49f1b7844eb9079b0255018a846df5ec0516e2c002a87).
Pinout follows the standard SOT-23-5 load switch layout, footprint geometry
matches SOT5P95X290X145N in lib/@contrib/ldo.

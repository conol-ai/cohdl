## Secondary land-pattern reference

Winbond does not provide a PCB land pattern for XH, so the local footprint
uses the perimeter and center-land geometry from KiCad
`Package_DFN_QFN:DFN-8-1EP_2x3mm_P0.5mm_EP0.61x2.2mm`. This is a secondary,
generic reference rather than Winbond authority and therefore does not remove
the assembly-validation requirement.

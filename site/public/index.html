The schematic is
source code.

CoHDL is a hardware description language for PCB schematics. A board is a program — typed, checked, and compiled to a netlist, bill of materials, footprints and fabrication data. No dragging symbols across a canvas, and no silent mistakes to find at the assembly house.

Read the docs See a real board

  • It refuses to guess

    Units are part of the type system. A resistor where a capacitor belongs, a 5 V part on a 3.3 V net, a pin left unconnected that must not be — each is a compile error naming the exact instance and pin, not a warning in a list nobody reads.

  • The same source, the same bytes

    Compilation is deterministic end to end. The same design and the same pinned libraries produce the same designators and a byte-identical netlist, so a board you build today is the board you rebuild in a year.

  • Parts you can actually buy

    Components come from versioned libraries with datasheet-verified pinouts and land patterns, pinned to exact versions and content hashes through the package registry.

  • Built for working with AI

    A language a model can write is a language a compiler can check. Every design is text, every error is precise and machine-readable, and the verdict is the same for a human and a machine.

From source to fab

One compiler carries a design from text to manufacturing data. Each stage must pass before the next is attempted, so an error is caught at the first stage that can name it precisely.

  1. 01

    Write

    Devices, nets and sub-circuits in plain .cohdl files. Components come from packages pinned to exact versions in a lock file — yours, the standard libraries, or the registry's.

  2. 02

    Check

    cohdl check climbs the verdict ladder — parse, resolve, type-check, connect, design-rule check. Every diagnostic carries a stable error code and the exact span, readable by people and machines alike.

  3. 03

    Build

    cohdl build emits the KiCad netlist, BOM, footprints, layout constraints and an IPC-2581 handoff document — deterministically, down to the byte.

Built with CoHDL

OpenMicroKbd

A 13-key macropad with a rotary encoder, an analog joystick, capacitive touch and 21 RGB LEDs — an STM32 board whose entire schematic is a few hundred lines of CoHDL. The compiler checked the design, emitted the netlist, BOM and footprints, and handed layout constraints straight to the autorouter. The board came back from the fab and worked.

# GD32F303CBT6

128 KB flash, 32 KB SRAM, Cortex-M4 up to 120 MHz, LQFP48.
Use `gigadevice_gd32::MCU_GD32F303CBT6`.
Primary evidence: the **GD32F303xB** Rev 1.1 datasheet, Figure 2-4,
Table 2-5, Figure 4-1, Figure 5-6 and Table 6-1; see [sources](sources.md).
The xB document is the source for this 128 KB part, rather than assuming all
features of the larger-memory GD32F303xx devices.

## Connections

- Connect all three VDD pins (24, 36, 48), all three VSS pins (23, 35, 47),
  VDDA pin 9 and VSSA pin 8. The model keeps every supply pin separate to
  support individual decoupling and physical placement.
- VDD and VDDA operate at 2.6-3.6 V, with VDDA the same as VDD. Figure 4-1
  specifies 100 nF at each VDD plus 4.7 uF bulk, 1 uF plus 10 nF for VDDA,
  and 100 nF at VBAT. All capacitors need short local return paths.
- Connect VBAT pin 1 to a valid backup supply or the main supply when backup
  operation is unused. With both supplies on, VBAT must be no more than
  VDD + 0.3 V. This package has no separate VREFP/VREFN or VCAP terminals.
- Establish BOOT0 pin 44 and account for PB2/BOOT1 pin 20 in the boot plan.
  Do not let attached peripherals defeat the selected reset-time levels.
- PA13 pin 34 and PA14 pin 37 are SWDIO/SWCLK; provide NRST pin 7 and ground
  access. JTAG functions also occupy PA15/PB3/PB4 until reconfigured.
- PD0/PD1 pins 5/6 default to OSCIN/OSCOUT. GPIO use needs a firmware remap;
  these pins cannot provide EXTI in this package (Table 2-5 note 4).
- USB uses PA11/PA12 pins 32/33, which also multiplex CAN0 RX/TX. Select
  interfaces and clocking deliberately. CAN requires an external transceiver.
  PC14/PC15 pins 3/4 can provide the low-frequency crystal connection.

## Land pattern

`qfp::QFP50P900X900X160_48N` from `qfp 0.2.0` matches Figure 5-6:
48 rectangular 1.20 x 0.30 mm lands, 0.50 mm pitch, 9.70 mm outside span,
7.30 mm inside span and 5.80 mm tangential span. Row centers are +/-4.25 mm.
Pin 1 is upper-left and the numbering is counterclockwise in component-side
view. There is no exposed pad. The shared 10.2 mm square courtyard encloses
the copper with 0.25 mm margin. The dependency originally transcribed this
geometry from ST; this binding independently checks it against GigaDevice's
identical recommendation. Shared copper geometry does not imply device
interchangeability.

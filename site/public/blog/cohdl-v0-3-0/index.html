CoHDL v0.3.0 is
out.

The compiler is open source, and for the first time you can install it without building anything: one line fetches a checksum-verified binary and puts a working toolchain on your machine.

Tony Huang · August 18, 2026

The source is public at github.com/conol-ai/cohdl, MIT licensed — the compiler, the component libraries, the reference designs, the registry server, and the VS Code extension. Installing the newest release is one line on macOS or Linux: 

curl -fsSL https://raw.githubusercontent.com/conol-ai/cohdl/main/install.sh | sh

The installer resolves the newest release with a build for your platform, verifies the download against the release's published sha256sums.txt, and installs to ~/.cohdl/bin. From then on the binary keeps itself current: cohdl self-update downloads and checksum-verifies a new release the same way and swaps the binary in place, and --check just tells you whether there is anything new.

What ships

  • Prebuilt binaries for five targets — macOS on Apple Silicon and Intel, static Linux builds for x86-64 and AArch64 that run on any distribution, and Windows x86-64 (downloaded by hand from the releases page; note the lsp server currently targets POSIX hosts — see Editor support). Building from source stays plain cargo build.
  • The whole toolchain in one binary — check, build, fmt, lsp, the registry verbs, and now self-update. The CLI reference covers all eleven.
  • A live ecosystem, not a bare compiler — the package registry serves the official component libraries with datasheet-verified parts; the VS Code extension is on the marketplace as conol.cohdl; and the language specification and all thirty-one RFCs are published on this site.

Why the first release is 0.3.0

The v0.1.0 and v0.2.0 tags were consumed by the previous implementation's releases in March — the codebase that taught us what the language had to become, and that this compiler replaced from a clean start. Rather than reuse version numbers that already point at different software, the rebuilt compiler's first shipped release is v0.3.0. The old implementation survives on the repository's legacy branch as reference material.

Where to go first

Getting started walks one small board through the whole loop — write, check, break it on purpose, build — with every transcript taken from the real toolchain. The language tour covers every construct, and the OpenMicroKbd case study shows the language shipping a physical product. If you build something, write in — the use-cases page is where real boards get collected.
